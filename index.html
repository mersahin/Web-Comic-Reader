Local helper (optional)

Not needed when you are signed in above. The helper adds web search (site:t.me) as an extra source, or lets you search without a Telegram account. Search engines do not let websites read their pages, so it has to run on a computer.

  1. Download tg_finder.py (needs Python 3).
  2. Run it and keep the window open:
    python3 tg_finder.py
  3. Optional, to read files directly here: create an API ID at my.telegram.org, pip install telethon, then start with
    python3 tg_finder.py --api-id 12345 --api-hash abcdef…
    The first start asks for your phone number and login code in that window. Your Telegram login stays on your computer.
  4. Chrome may ask to allow access to devices on your local network. Allow it.
